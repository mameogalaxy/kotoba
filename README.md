# 脳みそ仕分け

放り込んだ断片を Jev が自動で仕分けて、**未解決の問い**だけを溜めていく個人用の外部脳。

分類しない。フォルダも選ばない。入力欄に放り込むだけで、行き先が決まる。
そして次に似たことを打ち始めた瞬間、**打っている最中に**過去の自分が付箋で出てくる。

---

## 動かす

### スマホだけで完結させる（推奨）

**ブラウザは他サイトのAPIを直接叩けません（CORS）。** `api.typesafe.ai` も許可していないので、
GitHub Pages に置いただけでは通りません。中継をネット上に置く必要があります。

このリポジトリには Vercel 用の中継（`api/jev.js`）が入っているので、Vercel に繋ぐだけで
**アプリと中継が同じドメインに乗り**、CORS の問題自体が消えます。

1. [vercel.com](https://vercel.com) に GitHub アカウントでログイン
2. **Add New → Project** → このリポジトリを **Import**
3. 設定は何も触らず **Deploy**（フレームワーク検出も環境変数も不要）
4. 出てきた `https://....vercel.app` を開く
5. 右上 → APIキーを貼る → **「このサイトの中継を使う」** を押す

バッジが **「Jev 接続済み」** の緑になれば完了です。

### パソコンで動かす

```bash
node proxy.mjs          # → http://localhost:8787
```

設定のエンドポイントを `http://localhost:8787/jev` にします。
`proxy.mjs` はアプリの配信と中継を兼ねていて、依存パッケージはありません。

### 直接つなぐ

TypeSafe がブラウザからのアクセスを許可しているなら、`index.html` を開くだけで動きます。
設定の「直接つなぐ」で試せます（2026年9月時点では弾かれます）。

### バックアップ

データは端末のブラウザの中（localStorage）にしかないので、ブラウザのデータ消去や機種変更で消えます。
設定画面の「バックアップ」から保存・復元できます。

- **バックアップを保存** — iPhone では共有シートが開くので「ファイルに保存」や自分宛てに送る。
  共有シートが使えないブラウザではファイルとしてダウンロードする
- **文字でコピー** — ダウンロードできないアプリ内ブラウザ用。メモアプリなどに貼って保管する
- **ファイルから読み込む / 貼り付けて読み込む** — 今あるデータは消さずに足し合わせる。
  同じ項目があれば更新日時が新しい方を残す。自分で作った枝もあわせて戻る
- 中身はメモ・問い・結論・材料と枝の分け方。**APIキーは含めない**
- 10件以上あるのに2週間以上保存していなければ、開いたときに1日1回だけ知らせる

### APIキーとデータの扱い

キーは **この端末の localStorage** にだけ保存されます。中継（`api/jev.js` と `proxy.mjs`）は
ブラウザから来た `Authorization` ヘッダーを上流へ素通しするだけで、保存も記録もしません。
仕分けた項目も端末内にのみ残り、どこにも送信されません。

## Jev の使い方

### 仕分け（入力1件につき1リクエスト）

`state` は1回だけ送って、そこに9つの判定をぶら下げています。
state 分のトークンは一度しか払わないので、質問は多いほど割安になります。

| 質問 | 型 | 聞いていること |
|---|---|---|
| `unresolved` | Noul | まだ答えが出ていない問いか |
| `kind` | Choice | 疑問 / 調べかけ / アイデア / タスク / 事実メモ / 買いたい |
| `context` | Choice | 枝の分け方（設定で自由に変更。初期値は 仕事 / 副業 / お金 / 健康 / 人間関係 / 趣味 / 学び / 生活）+ その他 |
| `importance` | Score | 5段階の重要度 |
| `freshness` | Score | 数日 / 数週間 / 数ヶ月 / 年単位 |
| `isMaterial` | Noul | 既存の問いを進める材料か |
| `materialOf` | Choice | どの問いの材料か（既存 id から選ぶ） |
| `isAnswer` | Noul | 既存の問いの**答え**になっているか |
| `answerOf` | Choice | どの問いの答えか |

枝の分け方は設定画面で書き換えられます。1行に1つ `名前：どんなものが入るか` の形で30個まで。
**説明はそのまま Choice の選択肢の説明として Jev に渡します**。名前だけだと Jev に判断材料がなく、
多数派の枝に寄りやすかったため。当てはまらないものは「その他」へ。

**新しい枝ができたとき**（詳細画面の「＋ 新しい枝」でも、設定で書き足しても）:

1. **似た枝がないか確かめる** — 新しい枝と既存の枝の組ごとに「同じものを入れる分類として重なっているか」を
   Noul で聞く。全部の組を1つの state にぶら下げて1リクエストで済ませる。60% 以上なら
   「『タスク』と『やること』はよく似た枝です。まとめますか？」を出し、どちらにまとめるか／このままを選べる。
   まとめると項目を移して片方の枝を消し、説明も引き継ぐ
2. **過去の項目を引き寄せる** — まとめなかった新しい枝について、過去の項目を1件ずつ振り分け直し、
   新しい枝の確率が 60% 以上のものだけ移す。移した件数と例を知らせる

どちらの操作にも「元に戻す」がある。設定の「似た枝をさがす」で、全部の組をいつでも点検できる。

判定の state からは既存の問いの文脈を外しています（新しい断片が多数派の枝に引っ張られていた）。
設定の「今ある項目を振り分け直す」で、保存済みの項目を1件ずつ Jev に聞き直せます。
更新日時は変えないので、いま度の並びは崩れません。詳細画面の枝の札をタップすれば手でも直せ、
そこから「＋ 新しい枝」で自分の枝を作ってそのまま入れることもできます。

`isAnswer` が 0.55 を超えると「過去の問いに、いまの自分が答えているかもしれません」
が出ます。これがニューロンの正体です。

### 付箋（入力中）

2段構えです。

1. **ローカル（0ms・無料）** — 打った言葉が項目（見出し・材料・結論）の中に**どれだけ入っているか**で照合。
   そのまま含まれていれば最優先、そうでなければ2文字組（bigram）のうち何割が項目に入っているかを見る。
   「なん」「だっけ」のようなひらがなだけの組は数えない。項目の長さでは割らないので、
   長いメモの中の一語（「バス」など）でも当たる。打鍵のたびに走ります。
2. **Jev（70〜500ms）** — 2文字以上で打鍵が 350ms 止まったら、候補を `Choice` で1回投げる。
   メモも含めて渡し、見出しだけで中身が分からない項目には本文の冒頭60字も添える。
   返ってくる**確率分布をそのまま順位**に使っています。文字が一致していなくても
   意味で引けるのはこの層です。

LLM では 1〜3秒 / 約1円かかるため、この2段目は成立しません。
Jev の 70〜500ms・0.0001円 で初めて予測変換として成り立ちます。

### マインドマップ

既定の画面。中心が「いまの自分」で、文脈ごとに色分けした枝が
四隅へ伸び、各枝に項目がいま度の高い順に3件ぶら下がります。

枝の並びは**最近使った順**。いちばん最近使った4つが中心のすぐ隣（左上→右上→左下→右下）に来て、
しばらく使っていない枝ほど外側になる。「使った」は、その枝に入れた・中の項目を直した・項目や枝を開いたとき
（開いた記録は nou.catuse.v1）。並び替えは詳細を閉じたときにまとめて動く。

- **普段は完全に静止**。常に動く表示は読みにくいので、動くのは状態が変わったときだけ
- 入力欄はチャットと同じく**画面の下**。マップを見ながら打てる。1行から始まり、打つと伸びる。
  × で入力を一気に消せる
- 送った内容が既存の項目の材料になったとき（新しい項目なら入った枝に）、その項目を
  見える位置までスクロールして一瞬光らせ、「ここに入りました」の札を出す
- キーボード表示中は上の段を隠し、狭い高さに合わせて中心の円も小さくする
- **入力中は、候補が枝から抜けて中心の真下へ移動**し、残りの項目は詰めて並び替わる。
  候補以外は薄くなり、中心と候補のまとまりが見えている範囲の真ん中に来るよう自動でスクロールする
- キーボードが出たときは、見えている高さ（`visualViewport`）に合わせて画面を組み直すので、
  入力欄がキーボードの上に乗り、マップはその上の空間に収まる
- 新しく入れた項目は中心から芽を出して、自分の枝へ移動する
- 宙ぶらりんは実線、解決済みは ✓、メモは点線。鮮度が落ちたものほど薄い
- 文脈の札か「ほか N件」をタップするとその枝を全部広げる。項目のタップで詳細

レイアウトは決定的に計算していて（力学シミュレーションではない）、要素の移動は CSS の
transition に任せています。枝の点線だけは、動いている 0.7 秒の間だけ要素の実位置を
追いかけて引き直し、止まったら描画も止まります。

### 予測変換

今まで入れた文章から単語帳を作り、打ちかけの最後の言葉に合う単語を入力欄の上に出す。
タップすると打ちかけの部分がその単語に置き換わる。キーボードは閉じない。

- 単語帳は見出し・材料・結論から、英字の語（ChatGPT, SPA-HERBS）、カタカナ語（シャトルバス）、
  漢字の熟語（確定申告）を集める。よく出る語ほど上に来る
- 同じ文字の種類なら前方一致（`Cla` → Claude、`しゃと` → シャトルバス、`確定` → 確定申告）
- かなから英字表記（`くろーど` → Claude）は3段で当てる
  1. **覚えた組み合わせ** — 一度選んだ読みと単語の組は記憶して、次から最優先で出す（バックアップにも入る）
  2. **音の骨組み** — 読みをローマ字にし、英語の綴りと一緒に母音を落として c/k・l/r・j/g・v/b などを
     同一視した形で比べる（くろーど → krd、Claude → krd）。ちゃっとじーぴーてぃー → ChatGPT、
     てぃっくとっく → TikTok、あんそろぴっく → Anthropic も当たる
  3. **Jev** — 上の2つで当たらないかな（あだ名など）は、単語帳の英字の語を選択肢にして Choice で聞く。
     確率も表示する（`ちゃっぴー` → ChatGPT 82%）
- 読みで打っている途中は、予測変換の1位でもマップを探すので、`くろーど` だけで Claude の項目が中心に来る
- 詳細画面の「材料を足す」欄でも同じ予測変換が欄のすぐ下に出る。この欄を押すと、キーボードが出たあとに欄と「＋ 材料を足す」ボタンが見える位置まで自動で送る

### 【】で見出しを決める

入れる文章に【】で囲んだところがあると、その中身だけが見出しになる（「明日の打ち合わせで話す【新しい料金プラン】のこと」→ 見出し「新しい料金プラン」）。
【】は材料にはそのまま残り、日付（明日など）も文章全体から読む。【】が2つ以上あるときは最初のもの。
前から入っていた項目も、見出しを自分で直していなければ【】の中身にそろえる。

### 入れた文章を直す

詳細画面の**見出しも材料も、表示されている文字をそのままタップして直せる**。
欄は中身の長さまで伸びるので長い材料も全部見えたまま直せ、外をタップするかキーボードの
「完了」（見出しは Enter でも）で保存する。直している間は画面を描き直さず、お知らせだけ差し替える
（見出しから材料へ続けてタップしてもカーソルが飛ばない）。キーボード表示中は詳細画面も
見えている範囲に収め、直している行が隠れないよう送る。

- 見出しを直すと、見出しと同じ文章の材料も一緒に直る（「今日シフト作成」→「明日シフト作成」）
- 材料を直したとき、見出しがその材料から作られていたなら見出しも作り直す
- 材料が2つ以上あれば、材料の「消す」で不要な材料を消せる（見出しはそのまま）
- **保存すると Jev がその項目を振り分け直す**。項目の中身だけを state にして、
  枝・種類・重要度・鮮度・宙ぶらりんかを1リクエストで聞き直す。解決済みは解決済みのまま
- 枝が変わったら「仕事 → 生活 に移りました」と出し、詳細を閉じたときにマップ上の移動先を光らせる

### 入れた文章をコピーする

詳細画面の材料ごとに「コピー」、材料が2つ以上あれば見出しの横に「全部コピー」、
結論にも「コピー」が付く。ワンタップでクリップボードに入り、改行もそのまま残る。
クリップボードの API が使えないアプリ内ブラウザでは、選択してコピーする方法に切り替える。

### 入りそうな枝の札

空行で何件かに分かれるときは「① 納豆… → 生活 ▾」「② 研修資料 → 仕事 ▾」のように項目ごとに出し、入力欄の色の帯もその枝の色にする（項目ごとの予測は Jev 1回にまとめて聞く）。札を押すとその項目だけ枝を選び直せる。
打っている最中に、入力欄の上へ「🏷 趣味 に入りそう ▾」（その枝の色）を出す。予測は、候補さがしで Jev に送っている同じリクエストに
枝の Choice を1問相乗りさせたもの（まだ返事がないときは、枝の名前や近い過去の項目の枝から「入るかも」）。
そのまま入れれば予測の枝に入り、札を押すと枝を選び直せる（選んだ枝は入力欄の札になり、自分で決めた枝として扱う）。

### 新しい枝を作る

- **＋ボタンから**：入力欄の左の「＋」→「カテゴリーを指定して入れる」→ 枝を選ぶと、入力欄の頭に色つきの札が付く。
  隣に書いた文はその枝に入る（Jev の枝えらびより優先）。「＋ 新しい枝」なら札の中に名前を書き、隣の文ごと新しい枝に入れる。
  札だけで「入れる」を押せば枝を作るだけ。札の×か、空の入力欄で⌫を押すと札を外せる
- **入力欄から**：「新しい枝 旅行」「カテゴリー追加 推し活：アイドルやライブ、グッズのこと」のように入れる（「：」の後ろは説明）。
  作ると、今ある項目から Jev が当てはまるものを探して移す（元に戻せる）
- **当てはまらなかったときに提案**：新しく入れたものが「その他」になったか、どの枝にも30%未満でしか当てはまらなかったら、
  入れた文の言葉とよくある枝の名前（旅行・推し活・子育て…）から、Jev の Choice で新しい枝の名前を選ばせて
  「新しい枝『旅行』を作りますか？」と聞く。「名前を変えて作る」で詳細の新しい枝の欄が開く。断った名前は続けては聞かない
- **項目から**：詳細の枝の札「◯◯ ▾」→「＋ 新しい枝」
- **設定から**：「枝の分け方」に1行足す

### 自分で決めた枝と、枝の色

- 詳細の「枝 ▾」で選んだ・＋の札で指定した・提案を受けて作った枝に入れた項目は「自分で決めた」印が付き、
  直したとき・新しい枝で集め直すとき・「今ある項目を振り分け直す」のときに Jev が枝を変えない（その枝を消したときだけ動く）
- 枝の色は枝ごとに覚える（設定の `branchColors`）。ほかの枝を消しても色はずれず、新しい枝には使っていない色を割り当てる

### 枝の中身を見る・枝を消す

マップの枝の札（「仕事 5」など）をタップすると、上からパネルが出て、その枝の項目を1枚ずつのカードで見られる。
左右にスワイプ（または ‹ ›）でめくる。カードには種類・今日の札・繰り返し・リンク・材料・結論が出て、
「詳しく開く」で詳細、閉じると同じカードに戻る。「ほか◯件」は今までどおりその場で枝を広げる。

パネルの「この枝を消す」で枝を消せる。中の項目は Jev が残りの枝から選び直し、当てはまらなければ「その他」へ。
消したあとの知らせに「元に戻す」がある（「その他」は消せない）。

### 材料にくっつける条件

Jev の `isMaterial` / `isAnswer` には「日付や時刻が同じだけでは関係があるとしない」と指示している。
さらにコードでも、新しい文の枝と相手の項目の枝が違えば（仕事の研修と家族の誕生日など）くっつけずに別の項目にする（どちらかが「その他」なら許す）。
くっついてしまった材料は、詳細の材料ごとの「分ける」で別の項目にでき、枝は Jev が振り分け直す。

### 引っぱって更新
マップ・一覧のいちばん上で画面を下に引っぱり、「離すと更新」が出たところで離すとアプリを読み込み直す（新しい版が出ていればそれになる）。
ホーム画面に置いたアプリには Safari の引っぱって更新がないので自前で持っている。書きかけの入力は消えずに戻る。キーボードが出ている間は効かない。

### 今日の日付と天気

上の段は「9/23(水) ☔小雨 21° ↑26° ↓18° ☂80%」（太字が今の気温、↑最高・赤、↓最低・青、タップで文字の説明。15分ごとに更新）のように今日の日付と天気（一覧・マップの切り替えと凡例はなくした）。
日付の上に小さく年（2026）。祝日は赤で名前も出す（「2026 · 秋分の日」）。日曜は赤、土曜は青。祝日は端末内で計算していて、春分・秋分、ハッピーマンデー、振替休日、国民の休日も入る。祝日名が出る日は、天気の言葉を外して絵文字だけにする（幅が足りないため）。
天気は Open-Meteo（キー不要）から取る。位置は最初に「📍 天気を表示」を押したときだけ聞き、約1km（小数2桁）に丸めて覚える。
断られたら東京の天気。30分ごと・アプリに戻ったときに更新し、タップでもすぐ更新する。
天気は Jev の「今日のこと」の判定にも渡している（雨の日の洗濯など）。

### 日付をいくつも書いたとき

「9月休み / 24 免許更新 / 27 フレンダ / 30」のように、「◯月」の見出しの下に日にちだけ並べた書き方も読む（「9月休み 24、27、30」の1行も可）。
「10/7 ライブ / 10/12 飲み会」のように1項目に日付がいくつあっても、毎日その時点の**次の日付**で判定し直すので、
24 の前日は「明日 · 免許更新」、24 を過ぎれば 27 の「あと3日 → 明日 → 今日」と進む。
その日の用件は同じ行の言葉から取り、詳細には「期日 9/24(木) · 明日 · 免許更新」「ほか 9/27 フレンダ・9/30 休み」と出す。

日付は本文から読む。見出しは本文を30字で切ったものなので、「（28日間）」が「（28日…」になって
「28日」に見えることがあるため、切れた見出しは使わない。
「開始の14日前までに申請」のような書き方は、同じ文の中の一番早い日付から数えて締め切りにする（1/23 の14日前 → 「1/9まで · 申請」）。

時刻表・営業時間・料金表のような「見返すための情報」（その言葉があるか、時刻が3つ以上並ぶもの）は、日付がなければ予定にも今日にもしない
（Jev への「今日に関係するか」の指示にも書いてある）。それでも Jev が今日と言ったものは、詳細の「今日 ✕」で今日のことから外せる。

### 予定で探す

「予定」「今週の予定」「明日の予定」「来月の予定」と打つと、これからの予定（期日・曜日・繰り返しのある項目）を
近い順に出す（マップに出るのは4件まで）。札は「明日」「10/1(木)」「9/25(金) 8:00 🔁」のように次の日付。

種類に「予定」を足した。Jev が「事実メモ」と言っても、これから先の日付・曜日・時刻・繰り返しが書いてあればコードで「予定」にする
（「昨日パソコン買った」のように過去のことは変えない）。前からある項目も読み込むときに直す。

### 枝の名前で探す

「SNS」「副業」のように枝の名前（打ちかけも可）を打つと、その枝の項目を先に並べる。
「SNSの動画」のように名前を含む文なら、Jev と文字の照合で拾ったあと、空いた分をその枝の項目で埋める。
文字の照合には枝の名前も入れてあり、Jev の候補えらびにも各項目の枝を渡している。

### 日時で思い出す

「先週の夜に書いたやつ」「月曜の朝のメモ何だっけ」「9/15のやつ」のように打つと、
その時期に書いたもの（項目本体か材料のどちらか）が中心に集まります。

1. **手元（即時）** — 今日 / 昨日 / 一昨日 / 今週 / 先週 / 今月 / 先月、曜日、時間帯
   （深夜・早朝・朝・昼・午後・夕方・夜）、`9/15`・`3日前` を正規表現で読む。
   「夜の撮影」のように中身としての時間語に反応しないよう、「書いた」「やつ」「だっけ」などの
   探す言い回しがあるか、短い入力のときだけ動く
2. **Jev** — 付箋の順位づけと同じリクエストに4問相乗りさせる

   | 質問 | 型 | 聞いていること |
   |---|---|---|
   | `isRecall` | Noul | 過去に書いたものを探している問い合わせか |
   | `period` | Choice | 今日 … もっと前 / 指定なし |
   | `weekday` | Choice | 月曜 … 日曜 / 指定なし |
   | `timeOfDay` | Choice | 深夜 … 夜 / 指定なし |

   選ばれた時期を実際の期間（先週 = 先週月曜 0:00〜今週月曜 0:00 など）に直すのはコード側。
   確率 45% 未満の選択は「指定なし」扱いにして、思い込みで絞り込まないようにしている

**送信したときに `isRecall` が 60% 以上なら、保存せずに探した結果を中心に残します。**
判定が外れたとき用に「メモとして保存する」ボタンが出ます。打ち始めるか中心をタップすると元に戻ります。

書いた日時は、中心に来た候補の先頭（`9/15(火) 夜`）、詳細画面（`9月15日（火）22:10 · 夜`）、
材料ごとの時刻、リスト表示に出ます。

### 今日のこと

アプリを開いたとき、Jev が宙ぶらりんとメモの項目ごとに2問聞く。

| 質問 | 型 | 聞いていること |
|---|---|---|
| `today{k}` | Noul | 今日に関係するか（今日やる・今日が期日・今日の予定・今日確認すべき） |
| `risk{k}` | Noul | 忘れると困るか（期限・手続き・更新・約束・支払い・予約） |

- 項目を1つの一覧（state）にまとめ、30件ずつ 60問を1リクエストで聞く
- 各項目に**書いた日**を添え、「項目の中の『今日』『明日』は書いた日を基準に読む」と渡す。
  昨日書いた「明日休み」は今日のこと、昨日書いた「今日エアコン工事」は過ぎたこと、と判定できる
- **書いてある日付はコードで読む**（Jev に任せると「免許更新24日」を今日と取り違えた）。
  今日 / 明日 / 明後日 / `24日` / `9/24` / `3日後` / `金曜` / `来週の月曜` / `◯日まで` / `11月まで` / `月末` を、
  書いた日を基準に日付へ直す。今日なら今日、明日なら「明日」、6日以内なら「あとN日」の札。
  今日ではない日付がはっきり書いてあれば、Jev が今日と言っても今日扱いにしない。
  読んだ期日は Jev にも渡し、詳細画面にも「期日 9/24(木) · 明日」と出す
- 明日の用事は中心寄りに少し上乗せし、忘れると困るものなら「今日のこと」にも「明日」として並べる
- 判定はその日のうちは覚えておき、新しく入れた・直した項目だけ追加で聞く。キーがなくても期日の分は動く
- いま度に `55 × 今日の確率 + 35 × 忘れると困る確率 + 近さ（明日 25・あと数日 10〜18）` を足すので、該当する項目ほど中心に寄る
- 開いた直後は、今日のこと（今日 60% 以上、または忘れると困る 85% 以上）を10件まで、時刻の早い順に中心に集めて
  「今日のこと」として見せる。**中心の丸をタップするたびに通常の表示と入れ替わる**。打ち始めても通常の表示。日付が変わるか
  1時間以上離れて戻ってきたら、また「今日のこと」から見せる
- 枝の中の項目には「今日」「忘れずに」の札が付き、詳細には確率が出る

### 隠したメモ（Face ID）

パスワード・暗証番号・カード番号・APIキーなどは、入れたときに自動で●にして暗号化して保存する。

- **まずコードで探す**。「パスワード」「暗証番号」「PW」「pin」などの直後にある英数字・記号、
  `sk-…` などの鍵の形、正しいカード番号（Luhn）、大文字・小文字・数字が混ざった20文字以上の塊。
  見つかったら **Jev には何も送らず**に隠す。打っている途中の候補さがしにも●にした文字しか送らない
- コードで見つからなければ、いつもの仕分けに Noul `secret`（秘密の値そのものが書かれているか）を1問足し、
  70% 以上なら隠す。このときは文章が Jev に届いている
- 保存するのは暗号文と、値の部分を●にした見出しだけ（`🔒 Amazon パスワード: ●●●●●●`）。
  マップ・一覧・候補・今日のこと・枝分けは、全部この●の見出しで動く
- 見るときは項目をタップ →「Face ID で見る」。30秒で自動で隠れ、アプリを離れるとすぐ隠れる。
  見えている間はタップして直せる（保存するとまた暗号化される）。「隠すのをやめる」で普通のメモに戻せる
- 普通の項目も、詳細の「🔒 隠す」で隠せる。直した文字にパスワードが入ったときも自動で隠す
- パスワードがある項目では、ログインID・登録メールの値も●にする（見出しの行だけが見える）
- **空行（1行以上あけた所）では必ず分ける**。入力中から、分かれる項目ごとに入力欄へ薄い色が敷かれ、分かれ目に「✂ ここで分かれます」の線が出て、上に「✂ 2件に分けて入れます」と出る（見えている通りに入る）
- **いくつかまとめて貼っても1件ずつに分ける**。空行で分け、空行がなくても
  「ID・パスワードの行のあとに見出しの行、その下にまた ID・パスワード」ならそこで分ける。
  パスワードのない文章を空行で区切って入れたときは、Jev の Noul `separate`（別々の用件か）が 60% 以上なら分ける
- 「パスワード」「メールアドレス」だけの行の次の行は、その値として同じ項目に入れる。
  見出しがなく ID・パスワードから始まるまとまりは、空行があっても前の項目の続きにする
- 表示中は「メールアドレスをコピー」「パスワードをコピー」「IDをコピー」のように、値ごとに別々にコピーできる（「全部コピー」もある）

### リンク

メモに `https://…` や `www.…` を書くと、押して開けるリンクになる。

- 詳細画面の見出しのすぐ下と、一覧の各行に「🔗 App Store /app/id6473753684 ↗」のようなボタンが出る。別のタブで開き、
  App Store・YouTube などのリンクは iPhone ではそのアプリが開く
- マップと一覧では、リンクのある項目の頭に 🔗 が付く。**見出しにはリンクを入れない**（リンクだけのメモは「App Store」のようにリンク先の名前になる）。前からある項目の見出しも、開いたときに直す
- App Store のリンクは App Store の商品ページなので、それだけでは App Store が開く。番号でわからなければ、リンクの中のアプリ名か、見出しがアプリ名そのもののときはその名前で引く。YouTube・X・Instagram・LINE・TikTok・Gmail・
  Google マップ・Spotify・Slack・Discord・Facebook・Netflix・Chrome・Notion・Threads・ChatGPT・Claude・Google・PayPay・Gemini（gemini.google.com を開き、アプリがあればアプリに渡る）は
  アプリを直接開くアドレス（`youtube://` など）がわかっているので、「▶ YouTube を開く」を先に出す。アプリが入っていなければ開けない
- 直接開くアドレスがないアプリ（ウエルシア・トモズなど）は「▶ ショートカットで開く」を出す。iPhone の「ショートカット」で
  見出しから作った名前（「ウェルシアアプリ」なら「ウェルシアを開く」）のショートカットを作り、「Appを開く」を1つ入れておけば開く
- メモに `youtube://` のようなアプリのアドレスを書いても、押して開ける（`javascript:`・`data:` などは開かない）
- URL の中の `pass`・`token` などの文字では、パスワード扱いにしない
- 隠したメモの中のリンクは、Face ID で表示している間だけ出る

### 重複の確認

新しい項目を入れる前に、同じものがないか確かめる（隠したメモも普通のメモも）。

1. コードで見出しどうしの似かたを測り（「ログインID」「パスワード」のような、どれにもある言葉は外す）、似ているものを3つまで選ぶ
2. Jev に Noul で「同じものをもう一度書いたのか。名前が似ているだけの別のサイト・別の用件なら false」を聞く。
   隠したメモは●にした見出ししか送らない
3. 60% 以上なら上に知らせる：**登録しない（前のを残す）／前のを新しい内容に置き換える／別に登録する**。
   パスワードを変えたときは「置き換える」で、前の項目のまま中身だけ新しくなる

キーがないときは、ほぼ同じ見出し（似かた 0.9 以上）のときだけ知らせる。

**しくみ**：WebAuthn（パスキー）の PRF 拡張で、Face ID を通ったときだけ毎回同じ32バイトを受け取り、
HKDF で包み鍵にする。その包み鍵で ECDH P-256 の秘密鍵を AES-GCM で包んで保存し、公開鍵はそのまま置く。
隠すときは公開鍵だけで暗号化できる（項目ごとに使い捨ての鍵を作る ECDH + AES-GCM）ので、
Face ID が要るのは見るときだけ。開けた鍵は1分だけメモリに置く。

- iPhone の Safari・**iOS 18 以降**が必要（PRF に対応していないと登録の時点で断る）
- パスキーは iCloud キーチェーンに入るので、機種変更しても同じ Apple ID ならバックアップを読み込めば開ける
- **パスキーを消すと、隠したメモは二度と開けない**。パスキーはこのサイトのドメインに結びつくので、URL が変わっても開けない
- バックアップには暗号文と、包んだ鍵（`locks`）が入る。Face ID がなければ読めない

### 繰り返しの予定

「毎週月曜 燃えるゴミ 朝8時」「平日 9時半 朝会」「毎月25日 家賃」のような繰り返しは、コードで読んで、その日になったら今日のことに入れる。

| 書き方の例 | 読み方 |
|---|---|
| 毎日・毎朝・毎晩・日課 | 毎日 |
| 平日 / 毎週末・土日ごと | 月〜金 / 土日 |
| 毎週月曜・毎週月・木曜・毎週 月水金・毎月曜・火曜は毎週 | 毎週その曜日 |
| 隔週水曜・2週間ごと | 書いた週から2週に1回 |
| 毎月25日・毎月10日と25日 / 毎月末 | 毎月その日（31日がない月は末日）/ 月末 |
| 毎月第2火曜 | 毎月第何曜日 |
| 毎年4月1日 | 毎年 |
| 母の誕生日 3月5日・結婚記念日 2015/6/1・祖父の命日 11月2日 | 「毎年」と書かなくても毎年。年が書いてあれば「66歳」「11周年」も出す。1週間前から「あと5日」で寄せる。2/29 は平年なら 2/28 |
| 3日ごと / 1日おき | 書いた日から3日ごと / 2日ごと |
| 21時・朝8時・9時半・19:30 | 時刻（午後・夜は24時間に直す） |

- 5行以上の長いメモ（家計簿など）は、見出しと最初の2行からだけ繰り返しを読み、Jev にも聞かない（本文の「1年毎」などでメモ全体を繰り返しにしない）。詳細の「🔁 … ✕」で繰り返しを外せる
- 「定期的に」「毎回」のように繰り返しっぽいのにコードで読めないときだけ、仕分けのついでに Jev の Choice
  （型・曜日・日付・第何週・月）で選ばせて、項目に覚えておく
- その日なら「今日 8:00」、1時間前から「もうすぐ 11:00」、過ぎて30分までは「いま」、3時間過ぎたら「8:00 過ぎ」。
  前の日は「明日」として少し中心に寄せる。1分ごとに見直すので、開いたままでも札が変わる
- その日でなければ、Jev が今日と言っても今日にしない（「毎週月曜」の月曜や「毎月25日」の25日を1回きりの期日として読まない）
- 詳細に「🔁 毎週水曜 8:00 · 次 今日」と出る。その日は「今日の分は済みにする」で、その日だけ今日のことから外せる
  （解決にすると繰り返しも終わる）

### いま度

一覧の並び順は API ではなくローカル計算です。

```
いま度 = (重要度 / 5) × 0.5 ^ (経過日数 / 鮮度の半減期) × 100 ＋ 今日のことの上乗せ（最大 100）
```

鮮度の半減期は 数日=3日 / 数週間=21日 / 数ヶ月=90日 / 年単位=365日。
解決済みの結論も半減期の4倍を過ぎると「この結論は古いです」と出ます。
