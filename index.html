仕分けは TypeSafe の Jev（Noul / Choice / Score）が判定しています。 1回の入力につき、9つの判定を1リクエストにまとめて投げています。 データはこの端末の localStorage にだけ保存され、どこにも送信されません。

     

    設定

    この端末の localStorage にだけ保存されます。サーバーには送られません（APIへの通信を除く）。

    ブラウザは他サイトのAPIを直接叩けないことが多く（CORS）、その場合は このサイトの中継（/api/jev）を選んでください。 Vercel などに置いていれば、これで同一オリジンになり必ず通ります。 パソコンで node proxy.mjs を使う場合は http://localhost:8787/jev。

    マップの色つきの枝になる分類です。Jev は入れたものを、この説明と見比べて1つ選びます。 1行に1つ、名前：どんなものが入るか の形で、30個まで。 説明を具体的に書くほど、振り分けが正確になります。当てはまらないものは「その他」に入ります。

    🔒 隠したメモ（Face ID）

    パスワード・暗証番号・カード番号・APIキーなどは、入れたときに自動で●にして、暗号化して保存します。 見るときは Face ID。見つけたものは Jev に送らず、枝分けには●にした文字だけを使います。 Face ID の登録（パスキー）は iCloud キーチェーンに入ります。これを消すと、隠したメモは二度と開けなくなります。

    バックアップ

    メモ・問い・結論・材料と、枝の分け方を1つのファイルにまとめます。APIキーは入りません。隠したメモは暗号文のまま入るので、Face ID がないと読めません。 データはこの端末のブラウザの中にしかないので、ブラウザのデータを消したり機種変更したりする前に保存してください。
